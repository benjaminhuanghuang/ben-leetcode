# Complexity Analysis

## Time complexity

The time complexity of pair_sum_sorted is O(n) because we perform approximately N iterations using the two-pointer technique in the worst case.

The time complexity of is_palindrome_valid is O(n), where n denotes the length of the string. This is because we perform approximately n iterations using the two-pointer technique.

Time Complexity: O(N^2) where N is the length of the input array.

## Space complexity

We only allocated a **constant number of variables**, so the space complexity is O(1).

O(N) for the space used to store the output triplets.
